# Vasudha Nukala — academic website

A responsive, static GitHub Pages site: single-page academic homepage plus a separate notebook.

## Publish
1. Create a GitHub repository named `YOURUSERNAME.github.io` (or use an existing Pages repository).
2. Upload the **contents of this folder** to the repository root.
3. In repository Settings → Pages, select **Deploy from a branch**, branch `main`, folder `/ (root)`.
4. Visit `https://YOURUSERNAME.github.io/` after deployment.

## Personalize before publishing
- Replace the photo placeholder in `index.html` with your own image.
- Add `assets/Vasudha_Nukala_CV.pdf` and link it from the CV section.
- Confirm paper titles, coauthors, abstracts, public PDF/SSRN links, and presentation credits.
- Add Scholar and LinkedIn links if desired.
- Replace planned notebook entries with links to actual posts. Duplicate `notebook/posts/TEMPLATE.html` to start an article.
- The website uses Google Fonts; it falls back to system fonts if offline.

## Design
The homepage is inspired by the single-scroll academic layout of Golnaz Bahrami's website; the notebook is inspired by Sangmin Simon Oh's restrained text-first design. This is an original implementation.
